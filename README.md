# نمایش تبلیغ تپسل (Native)

برنامه اندروید (Kotlin) برای نمایش تبلیغ همسان تپسل؛ با کلیک روی دکمه «تبلیغ جدید» تبلیغ قبلی حذف و تبلیغ جدید دریافت می‌شود.

## گرفتن APK با GitHub
1. یک ریپوی جدید در گیت‌هاب بسازید و محتوای همین پوشه را در آن آپلود/پوش کنید.
2. به تب **Actions** بروید؛ workflow با نام **Build APK** خودکار اجرا می‌شود (یا Run workflow بزنید).
3. بعد از اتمام، از بخش **Artifacts** فایل `app-debug-apk` را دانلود کنید.

## تنظیمات
کلید تپسل و شناسه تبلیغ در `app/src/main/java/ir/jaber/tapselladdemo/Config.kt` قرار دارند.
